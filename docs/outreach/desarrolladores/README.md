# Kit de Reclutamiento Técnico — Glass World Studio

> **Eje 2** de las Alianzas Estratégicas: **Desarrolladores y Arquitectos de Software**.
> **Glass World Studio (GWS) busca Alianzas Estratégicas: Inversores, Desarrolladores y Logística.**
> Orden de prioridad: 1) Inversores y capital · 2) Desarrolladores · 3) Logística (pilar operativo).
> Objetivo: sumar **pocas personas, muy buenas**, al núcleo técnico.
> Última actualización: 16-10-2026

No es una búsqueda corporativa. Es una **etapa fundacional**: buscamos gente que quiera
**construir**, no cubrir una vacante.

## Cómo se usan juntos

```
Paso 1 (Día 0)   →  Invitación con el gancho TÉCNICO. Una pregunta, no una oferta
Paso 2 (Día +3/4)→  El desafío real (sin pedir nada). Mostrar que el problema es grande
Paso 3 (Día +5/7)→  La charla del rol, con salida elegante
                            ↓
                     CHARLA  →  perfil técnico  →  primera tarea (prueba mutua)  →  se pactan condiciones
```

---

## Los 3 sub-perfiles

| `perfil` | Para quién | Énfasis |
|---|---|---|
| `fullstack` | Full-stack / producto | Que lo lleve de punta a punta |
| `b2b` | Backend / marketplaces B2B | Transaccional: licitaciones, matching, pagos, trazabilidad |
| `multiagente` | Arquitectos de IA / MCP | Enjambre de agentes y los 5 satélites |

---

## Guardarraíles de honestidad

- ✅ **Sí:** un problema grande, una arquitectura definida, una base en producción, autonomía técnica.
- ❌ **No:** salario de empresa grande, equipo armado, métricas que no existen, producto terminado.
- ❌ **Nunca** prometer un porcentaje o un sueldo que no esté pactado. Se dice *"las condiciones
  las charlamos"* — y se cumple.
