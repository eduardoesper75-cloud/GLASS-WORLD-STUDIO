## Reglas de la campaña

| Regla | Detalle |
|---|---|
| **Máximo de toques** | 3. Nunca un cuarto mensaje. |
| **Ritmo** | Humano: 1 toque cada 3–7 días. Nunca dos el mismo día. |
| **Personalización obligatoria** | Cada mensaje cita **un dato real** del interlocutor (tesis, portfolio, foco). Sin eso, no se envía. |
| **Longitud** | Paso 1 y 2: ≤ 120 palabras. Paso 3: ≤ 80 palabras. |
| **Canal** | Email para fondos; LinkedIn para *business angels* y directivos. Se ajusta el largo. |
| **Tono** | De socio a socio. Frases cortas. Cero jerga corporativa. |
| **Cierre** | Sin respuesta tras el Paso 3 → **archivar**. Reintento en 2–3 meses con una novedad real. |

**El error que mata la campaña:** mandar el deck en el primer mensaje. Primero la señal, después
el valor, al final la charla. Y nunca sonar como si necesitaras el dinero: **el que trae el
mercado, propone.**

## Qué NO hacer

1. **No adjuntar el deck en el primer mensaje.** Quema el activo.
2. **No sonar necesitado.** Traés un mercado de medio billón + el 60% invisible que nadie mide: proponés, no rogás.
3. **No imprimir un porcentaje.** La participación es generosa y se **pacta**, no se anuncia por escrito.
4. **No afirmar tracción que no existe.** Sin usuarios pagos, sin transacciones, sin ingresos. Decilo primero.
5. **No prometer métricas sin supuesto escrito.** Ver los guardarraíles del deck.
6. **No automatizar el envío.** El valor de esta secuencia es que la escribe una persona.
