## Reglas de la campaña

| Regla | Detalle |
|---|---|
| **Máximo de toques** | 3. Nunca un cuarto mensaje. |
| **Ritmo** | Humano: 1 toque cada 3–7 días. Nunca dos el mismo día. |
| **Personalización obligatoria** | Cada mensaje cita **un dato real** del inversor (tesis, portfolio, foco sectorial). Sin eso, no se envía. |
| **Longitud** | Paso 1 y 2: ≤ 120 palabras. Paso 3: ≤ 80 palabras. |
| **Canal** | Email para fondos; LinkedIn para *business angels* y directivos. Se puede duplicar con ajuste. |
| **Cierre** | Sin respuesta tras el Paso 3 → **archivar**. Se puede reintentar en 2–3 meses con una novedad real. |

**El error que mata la campaña:** mandar el deck en el primer mensaje. Nadie invierte sin
contexto. Primero la señal, después el valor, al final el pedido.

## Qué NO hacer

1. **No adjuntar el deck en el primer mensaje.** Quema el activo.
2. **No afirmar tracción que no existe.** Hoy no hay usuarios pagos ni transacciones. Decirlo antes de que lo pregunten.
3. **No enviar el mismo texto a dos inversores del mismo fondo.** Se hablan entre ellos.
4. **No prometer métricas ni proyecciones sin supuesto escrito.** Ver los guardarraíles del deck.
5. **No automatizar el envío.** El valor de esta secuencia es que la escribe una persona.
