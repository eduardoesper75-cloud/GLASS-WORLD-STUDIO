## 2. Criterios de evaluación (para puntuar cada candidato)

| Criterio | Pregunta |
|---|---|
| **Especialización en frágil** | ¿Tiene experiencia real con vidrio o arte? |
| **Cobertura** | ¿Llega a los mercados donde están los usuarios? |
| **Seguro** | ¿Ofrece cobertura de carga incluida o como opción? |
| **Trazabilidad / API** | ¿Se puede integrar el seguimiento a la plataforma? |
| **Precio** | ¿Es competitivo para las familias de carga clave? |
| **Tiempos** | ¿Cumple con los plazos que promete? |
| **Trato PYME** | ¿Trabaja con volúmenes chicos al principio? |

---

## 3. Prioridad de validación (por dónde empezar)

1. **Carga terrestre regional (AR/LatAm)** — es donde habrá primeras transacciones.
2. **Courier internacional** — piezas chicas de arte (alta frecuencia potencial).
3. **Empaque / crating** — habilitador: sin caballete no hay vidrio plano.
4. **Forwarding marítimo** — cuando arranque la exportación.
5. **Seguro de carga** — transversal, se suma a todas las categorías.
